# Release Checklist

## 1. 产品

- [ ] 游戏名称最终确认
- [ ] 介绍与实际玩法一致
- [ ] 图标
- [ ] 截图
- [ ] 视频（如需要）

## 2. 版本

- [ ] Version Code
- [ ] Version Name
- [ ] Release Notes
- [ ] Build 配置已记录

## 3. 技术

- [ ] Release Candidate 构建成功
- [ ] 微信真机通过
- [ ] 抖音真机通过
- [ ] 关键错误为 0
- [ ] 资源加载策略确认
- [ ] 包体/分包实际测量

## 4. 平台与合规

- [ ] 主体信息核对
- [ ] AppID 核对
- [ ] 软著/相关资质核对
- [ ] 备案/审批要求按当前官方规则核验
- [ ] 隐私政策
- [ ] 用户协议（如适用）
- [ ] 实名/防沉迷（如适用）
- [ ] 广告合规
- [ ] 域名/网络配置（如适用）

## 5. 安全

- [ ] Git 中没有 Secret
- [ ] API Key 不进仓库
- [ ] App Secret 不进仓库
- [ ] 广告密钥不进仓库
- [ ] 日志无敏感信息

## 6. 发布授权

**没有用户明确授权，不得执行以下动作：**

- 上传正式版本
- 提交审核
- 发布线上版本
- 灰度/全量发布
- 删除线上资源

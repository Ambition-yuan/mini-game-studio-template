# Roadmap

## 当前阶段

**Phase 0 — 环境确认**

## 阶段门

### Phase 0 — 环境确认

完成条件：
- [ ] Cocos Creator 可用并确认具体版本
- [ ] Node.js 可用
- [ ] Git 可用
- [ ] VS Code 可用
- [ ] 微信开发者工具可用
- [ ] 抖音开发者工具可用
- [ ] 微信 AppID 已有或明确状态
- [ ] 抖音 AppID 已有或明确状态

### Phase 1 — 产品定义

输出：`product-brief.md`、`gdd.md`、本文件更新。

完成条件：核心循环、MVP、明确不做项均已确定。

### Phase 2 — 技术设计

输出：`technical-design.md`。

完成条件：代码结构、平台适配、存档、广告、资源加载策略确定。

### Phase 3 — 可玩原型

完成条件：一局可完整玩完并重新开始。

### Phase 4 — 正式内容

完成条件：正式 UI、素材、音频、引导、核心数值进入可测试版本。

### Phase 5 — 平台能力

完成条件：微信/抖音平台层完成，平台差异集中封装。

### Phase 6 — 素材生产

完成条件：正式资源具备来源记录、命名规范、授权确认。

### Phase 7 — QA

完成条件：核心用例通过；阻断性问题为 0。

### Phase 8 — 性能与包体

完成条件：有实际测量记录，并处理主要瓶颈。

### Phase 9 — 合规/资质

完成条件：根据当前游戏与平台要求完成适用项核验。

### Phase 10 — 提审

完成条件：Release Candidate 可复现、资料一致、真机通过。

### Phase 11 — 上线后

完成条件：至少收集启动、核心漏斗、广告、错误和留存数据。

## 任务原则

每个任务只解决一个主要问题。每个任务都要有“目标 / 非目标 / 验收 / 验证”。

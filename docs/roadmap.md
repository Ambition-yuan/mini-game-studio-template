# Roadmap

| Phase | 目标 | 输出 | Gate |
|---|---|---|---|
| 0 | 环境确认 | status | 开发工具可用 |
| 1 | 产品定义 | Brief/GDD | 用户确认玩法 |
| 2 | 技术设计 | technical-design | 可实现且范围可控 |
| 3 | Graybox | 可玩原型 | 用户试玩通过 |
| 4 | 正式开发 | 完整首版 | 功能完成 |
| 5 | 平台能力 | 双平台适配 | 平台核心能力通过 |
| 6 | 素材完善 | 正式视觉/音频 | 内容完成 |
| 7 | QA | 自动化记录 + 用户真机默认通过 | 无用户失败反馈且 P0/P1 清零 |
| 8 | 性能 | 优化报告 | 达到目标设备基线 |
| 9 | 合规 | 发布材料 | 资质/资料就绪 |
| 10 | 提审 | RC 包 | 用户授权提交 |
| 11 | 运营 | 指标与问题清单 | 决定下一迭代 |

## 每个 Phase 的通用 Gate

- 输出物齐全
- 验收标准达成
- 风险已记录
- `docs/status.md` 已更新
- 未经用户确认不跨越关键产品/发布门

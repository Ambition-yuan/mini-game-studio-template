# Operations & Metrics

## 核心漏斗

```text
曝光 → 点击 → 启动 → 首局开始 → 首局完成 → 二次游戏 → 广告观看 → 留存
```

## 首版建议观察

- 启动成功率
- 首局开始率
- 首局完成率
- 平均游戏时长
- D1/D3/D7 留存（可取得时）
- 激励广告展示率
- 激励广告完成率
- 广告收入 / 用户（可取得时）
- 崩溃/异常率
- 关键流失节点

## 迭代原则

一次迭代优先解决一个明确问题。改变核心玩法前，先保留旧版本基线数据。

## 版本实验

每次 A/B 实验记录：

- 假设
- 修改项
- 目标指标
- 影响范围
- 开始时间
- 结束时间
- 结论

# Douyin Mini Game

## 规则

- 当前平台规则、审核、资质、API 与限制必须以抖音开放平台官方资料为准。
- 不把微信平台规则直接套到抖音。
- 不上传、提审、发布，除非用户明确授权。

## 常见工作流

Cocos 构建 → 抖音开发者工具 → 模拟器 → 真机 → 修复 → 再构建。

## 重点验证

- 启动与生命周期
- 广告与回调
- 存储/用户数据（如使用）
- 网络与安全域名（如适用）
- 包体/分包
- 真机兼容性
- 审核资料与游戏实际内容一致

## 资质

涉及软著、备案、版号/出版审批、实名认证、防沉迷等问题时，必须按游戏实际情况区分“必须”“适用时”“当前无需”，并保留证据来源。

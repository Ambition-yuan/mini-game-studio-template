# WeChat Mini Game

## 规则

- 只在任务确实涉及微信平台时使用。
- 平台行为与限制优先查微信官方文档和当前 Cocos 文档。
- 不假设历史 API 仍可用。
- 不上传、提审、发布，除非用户明确授权。

## 常见工作流

Cocos 构建 → 微信开发者工具打开 → 模拟器验证 → 真机验证 → 修复 → 再构建。

## 需要重点验证

- 启动
- 生命周期
- 存储
- 网络
- 广告
- 分享（如使用）
- 包体/分包
- 真机性能

## 结束输出

记录：工具版本、构建结果、真机结果、剩余问题、是否达到下一阶段 Gate。

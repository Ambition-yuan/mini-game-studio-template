# Skill: Game Phase Execution

## Purpose

帮助 Codex 按项目阶段推进，不跨阶段大规模实现。

## Procedure

1. 读取 `AGENTS.md`。
2. 读取 `docs/roadmap.md`。
3. 读取与当前阶段相关的文档。
4. 输出本任务 Goal / Non-goals / Acceptance / Validation。
5. 完成最小可验证修改。
6. 运行实际可用的检查、构建或真机验证。
7. 更新必要文档。
8. 汇报变更、验证、风险和下一步。

## Stop Conditions

遇到核心产品决策、账号授权、正式上传/提审/发布、不可逆修改时停下来，请用户确认。

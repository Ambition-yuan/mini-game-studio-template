# Release

## 目标

把开发中的版本转换为可审查、可复现、可提交的 Release Candidate。

## 流程

1. 读取 `docs/release-checklist.md`、`docs/qa-checklist.md`、`docs/status.md`。
2. 确认版本号、构建配置和 Git 工作区状态。
3. 运行发布前检查与相关构建。
4. 验证微信与抖音真机。
5. 核对游戏名称、简介、截图、图标、资质、隐私/协议等资料。
6. 对当前平台规则执行最新官方资料核验。
7. 输出“可以提交”或“不可提交”的结论及阻断原因。

## 安全边界

可以：准备包、检查资料、生成提交清单、说明操作步骤。

默认不可以：上传、提交审核、发布、修改线上配置。

这些动作只有在用户明确授权后才能执行。

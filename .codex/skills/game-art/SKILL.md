# Game Art

## 目标

保持风格一致、体积可控、授权清晰、可程序化组合。

## 流程

1. 读取 GDD，确认美术需求不是猜测。
2. 建立简短 Visual Bible：风格、色彩、线条、光照、细节密度、UI 语言。
3. 先做少量关键资产定风格，再批量生产。
4. 原始 AI 产物先整理再入库。
5. 对商业使用记录来源、工具、日期、提示词/生成批次（如适用）。
6. 按平台和引擎需求优化尺寸、格式、图集和音频。

## 命名

使用英文稳定命名，例如：

`player_idle_01.png`
`product_milk.png`
`btn_start.png`
`bg_supermarket_01.png`

禁止使用“最终版/最终版2/真的最终版”等命名。
